# AI 图片质量分析助手 - V1

## 概述

**AI 图片质量分析助手**是一个隐私优先的浏览器工具，帮助摄影师通过智能AI分析快速评估和改进他们的作品。采用零服务端存储设计，提供5位摄影师风格的多人格评析，实时反馈构图、光线、色彩和主体四个维度的得分，并生成可执行的Lightroom/Photoshop修图步骤。

**核心特性：**

- 🔐 **零后端存储**: 所有处理都在你的浏览器内完成，图片不会上传到服务器
- 🎯 **多人格AI**: 5位摄影师风格评析（卡蒂埃-布列松、安塞尔·亚当斯、范何、彼得·林德伯格、柯达Portra）
- 📊 **结构化反馈**: 4个维度评分，详细评分理由
- 🖼️ **即插即用**: 生成Lightroom兼容的XMP文件
- ⚡ **隐私优先**: EXIF自动清理，API密钥本地加密，刷新即清空数据

## 快速开始

### 1. 上传图片

- 拖拽或点击上传 JPEG、PNG、WebP 格式图片
- 支持大小：最大 50MB（推荐 ≤10MB）
- EXIF 数据自动提取并清理（保护隐私）

### 2. 选择评析风格

从 5 位摄影师风格中选择：

- **街拍叙事**: 决定性瞬间、构图叙事（卡蒂埃-布列松）
- **风景史诗**: 色调范围、景深层次（安塞尔·亚当斯）
- **城市几何**: 光影几何、极简构图（范何）
- **人像质感**: 肌理保真、眼神光、自然感（彼得·林德伯格）
- **胶片色彩**: 柔和色调、色彩丰富（柯达Portra）

### 3. 获取AI评分

即时获得4个维度的评分：

- ✅ **构图**: 主体位置、视觉流向、负空间
- ✅ **光线**: 曝光准确度、对比度、光线质感
- ✅ **色彩**: 色调和谐、饱和度、色彩氛围
- ✅ **主体**: 清晰度、焦点准确、质感丰富

### 4. 导出结果

- 下载Lightroom XMP侧车文件，一键导入
- 查看修图步骤（曝光、清晰度、色调曲线等）
- 支持迭代评估，任务链接跟踪改进过程

## 功能特性

### 图片上传与处理

- **拖拽或点击**上传 JPEG、PNG、WebP、HEIC、RAW 格式
- **自动压缩** via Canvas API（最长边4096px，JPEG质量0.85）
- **EXIF清理**: 移除位置信息和设备序列号，保留曝光数据（ISO、光圈、快门）
- **文件限制**: 单张最多50MB，推荐≤10MB获得最佳性能

### 风格识别

- 自动多标签分类（城市、纪实、风景、人像、街拍等10个分类）
- Top-3风格权重引导Agent推荐
- 轻量级规则引擎（MVP）或MobileNet模型（第2阶段）

### AI多人格评析

- **5位摄影师风格**，各具独特美学标准
- **4维度评分** (构图、光线、色彩、主体)，0-100分级+评分理由
- **动态提示词** 组合系统提示、Agent特定提示、EXIF和风格上下文
- **多AI供应商支持**: OpenAI Vision、Google Gemini、Claude 3

### 修图指导

- **结构化步骤** (Lightroom/Photoshop)，含具体参数
- **参数映射** 直接对应Lightroom滑块调整
- **风格感知建议** 基于选定的摄影师风格
- **XMP侧车生成** 供Lightroom直接导入

### 本地历史与任务链接

- **IndexedDB存储** 最近10次评估，含缩略图
- **任务链接** via parentTaskId，支持迭代改进工作流
- **一键重评** 含历史记录浏览
- **数据清空** 单键清除所有本地数据

## 系统架构

```
浏览器 SPA (Vite + React 18 + Tailwind + ShadcnUI)
├── 上传与预处理
│   ├── Canvas 压缩和格式转换
│   ├── EXIF 提取与清理
│   └── 缩略图生成
├── 风格识别
│   ├── 规则引擎 (MVP) 或 MobileNet (第2阶段)
│   └── Top-3 标签权重
├── Agent 推荐
│   ├── 标签-人格匹配
│   └── 评分算法
├── 动态提示词组装
│   ├── 系统提示模板
│   ├── Agent 特定提示
│   ├── EXIF 上下文注入
│   └── 风格标签上下文
├── AI API 集成
│   ├── OpenAI Vision
│   ├── Google Gemini Pro Vision
│   └── Anthropic Claude 3
├── 结果验证
│   ├── JSON 架构校验
│   └── 错误处理与降级
├── 结果展示
│   ├── 雷达图 (4维度)
│   ├── 评分卡片
│   └── 分步指导
└── 导出引擎
    ├── XMP侧车生成
    └── 预设文件下载

存储:
├── IndexedDB: 任务历史 (最多10条)
└── LocalStorage: 加密API密钥 (AES-GCM)
```

## 核心设计原则

### 零后端存储

✅ 图片不上传到服务器  
✅ 无数据库持久化  
✅ 所有计算在浏览器内  
✅ 刷新自动清空数据

### 隐私优先

✅ EXIF 自动清理（位置信息移除）  
✅ API 密钥本地加密 (AES-GCM)  
✅ 无追踪和分析  
✅ 可选"阅后即焚"模式

### 静态部署

✅ 支持 Vercel、Netlify、GitHub Pages  
✅ CORS 代理转发 API 调用  
✅ 零服务器维护  
✅ 全球 CDN 分发

### BYOK 模式 (自带密钥)

✅ 用户提供自己的 API 密钥  
✅ 无需账户注册  
✅ 无订阅费用  
✅ 完全成本透明

## 快速入门

### 安装

```bash
git clone <repository-url>
cd ai-image
npm install
npm run dev
```

### 配置

1. **添加 API 密钥** (设置面板):
   - OpenAI Vision: https://platform.openai.com/api-keys
   - Google Gemini: https://aistudio.google.com/app/apikey
   - Claude: https://console.anthropic.com/account/keys

2. **密钥存储**:
   - AES-GCM 加密
   - 仅存储在浏览器 localStorage
   - 不会发送到第三方服务

3. **首次评估**:
   - 点击"上传图片"或拖拽文件
   - 等待风格识别 (~1-2秒)
   - 查看推荐Agent
   - 选择偏好风格
   - 查看结果并下载XMP

## 安全与合规

### 数据保护

- EXIF清理: 移除GPS、设备序列号
- 密钥加密: AES-GCM 256位 (Web Crypto API)
- 无第三方服务: 无追踪和分析
- 威胁模型: API密钥泄露、提示词注入

✅ 数据最小化（图片不存储）  
✅ 首次使用时获取用户同意  
✅ "删除所有数据"按钮  
✅ 无个人数据收集
